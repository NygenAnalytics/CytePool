# Figures

{mod}`cytepool.plotting` draws, in one call each, the figures that limma, edgeR,
DESeq2, speckle and metafor draw, from CytePool's cubes and results. It needs
matplotlib: install CytePool's `plot` extra (`pip install "cytepool[plot]"`), or
matplotlib itself.

```{eval-rst}
.. automodule:: cytepool.plotting
```
