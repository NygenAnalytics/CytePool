# Bibliography

These are the works that the pages of this site cite and that CytePool's modules cite in
their References sections, which `help()` shows. The groups below say where each is
used; the list at the end of the page gives every work in full, with its DOI where it
has one. [How to cite](citing.md) says which to cite for each function.
